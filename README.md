# Privát Glončák – návrh webu

Návrh webu pre ubytovanie Privát Glončák v Zuberci v štýle značkovaného turistického chodníka: pásové značky ako farebný kód sekcií, smerovník s orientačnými časmi pešo, miestopisná tabuľa so súradnicami, informačná tabuľa náučného chodníka, smerovník s túrami a koncová značka v cieli.

Ide o návrh: ceny, obsadenosť a formulár sú ukážkové, nič sa neodosiela. Stránka má `noindex`, aby ju vyhľadávače zatiaľ neindexovali.
